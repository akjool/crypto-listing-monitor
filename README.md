# Crypto Listing Monitor — скилл для ИИ-агента

Скилл `crypto-listing-monitor` превращает ИИ-агента (Claude и другие агенты, поддерживающие формат SKILL.md) в монитора листингов и новостей по конкретному токену. По умолчанию настроен на **ECR (eCurrency)** и пару **ECR/USDT**.

## Что делает
- **Актуальность на день запроса.** Каждый факт идёт с датой; всё старше 7 дней помечается как устаревшее.
- **Листинги на любой площадке.** Проверяет известные биржи (XT.COM) и ищет новые CEX/DEX, включая перенос, отмену и делистинг.
- **Защита от клонов.** Сначала фиксирует «паспорт токена» (блокчейн + адрес контракта). Листинги и пулы с другим контрактом отбрасываются — тикер ECR не уникален.
- **Уровни доверия к источникам.** Биржа → проект → агрегаторы → СМИ. Слухи не считаются подтверждением.
- **Новости.** Короткая сводка свежих новостей проекта своими словами, с датой и источником.
- **Сравнение с прошлой проверкой.** Если передать агенту прошлый отчёт, он покажет, что изменилось.
- **Отчёт на русском:** итог в одну строку, таблица листингов, изменения, новости, предупреждения, где искали, источники.

## Установка
1. Положите `SKILL.md` в папку `crypto-listing-monitor/` в каталоге скиллов агента (или вставьте текст в системный промпт, если агент не поддерживает скиллы).
2. У агента должен быть доступ к веб-поиску и чтению страниц — без этого скилл не работает.

## Использование
Примеры запросов:
- «Проверь листинг ECR»
- «Что нового по ECR за неделю?»
- «Вот прошлый отчёт: … Что изменилось по ECR?»
- «Проверь листинг токена XYZ» — скилл подставит другой токен.

Для регулярного мониторинга настройте ежедневный запуск по расписанию и передавайте в каждый запуск предыдущий отчёт.

## Ограничения
- У агента нет памяти между запусками — для раздела «Что изменилось» прошлый отчёт нужно передать вручную или через расписание.
- Скилл не даёт инвестиционных советов и прогнозов цены.
